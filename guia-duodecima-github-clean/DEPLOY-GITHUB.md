# Publicar no GitHub Pages

1. Extraia o ZIP.
2. Coloque **o conteúdo da pasta**, não o ZIP, na raiz do repositório.
3. Confirme que `index.html` aparece na raiz.
4. Faça commit/push.
5. Vá a **Settings → Pages**.
6. Em Source escolha **Deploy from a branch**.
7. Selecione `main` e `/(root)`.
8. Salve e aguarde o deploy.

A aplicação usa apenas caminhos relativos e funciona tanto no domínio raiz quanto em `usuario.github.io/nome-do-repositorio/`.
