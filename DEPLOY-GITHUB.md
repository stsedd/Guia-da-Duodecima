# Deploy no GitHub Pages

1. Extraia o ZIP.
2. Envie **os arquivos de dentro do ZIP diretamente para a raiz** do repositório.
3. Confirme que `index.html` aparece na primeira tela do repositório, e não dentro de outra pasta.
4. Em **Settings → Pages**, escolha **Deploy from a branch**.
5. Selecione `main` e `/(root)`.
6. Salve e aguarde a publicação.

A aplicação usa caminhos relativos e funciona em `usuario.github.io/repositorio/`.
